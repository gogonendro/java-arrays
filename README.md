# java-arrays
Java programs based on Arrays

## What this repository contains
This repo contains two folders,
**SDA**, which carries 15 programs based on Single-Dimensional Arrays
**DDA**, *programs yet to be pushed*

### SDA
This folder contains 15 Single Dimension Array programs as follows:
1. **arr_sum**: to find the sum of the elements
2. **avg**: to find the average of the elements
3. **largest**: finds the largest element
4. **smallest**: finds the smallest element
5. **even_odd**: finds the number of even and odd elements
6. **search**: searches for a given element from an array (*linear search*)
7. **reverse**: reverses the elements
8. **secLarge**: finds the second largest element
9. **secSmall**: finds the second smallest element
10. **freq**: finds the frequency of a given element
11. **repDel**: deletes repeating elements
12. **ascSort**: sorts the element in ascending order
13. **merge**: merges the elements of two arrays
14. **common**: displays the common elements between two arrays
15. **rotate**: rotates an array to the left

# java-arrays

Java programs based on **Arrays**, covering Single-Dimensional Arrays (SDA) and Double-Dimensional Arrays (DDA) at the Class XII level

## What this repository contains

This repository contains **30 Java programs**, divided into two sections:

- **SDA** — Single-Dimensional Array programs
- **DDA** — Double-Dimensional Array programs

---

## 1. Single-Dimensional Arrays (SDA)

Programs based on operations and problems involving one-dimensional arrays

1. **Array Sum** — calculates the sum of all elements of an array.
2. **Average** — calculates the average of the elements of an array.
3. **Largest** — finds the largest element in an array.
4. **Smallest** — finds the smallest element in an array.
5. **Even Odd** — separates or identifies even and odd elements.
6. **Search** — searches for an element using linear search.
7. **Reverse** — displays the elements of an array in reverse order.
8. **Second Largest** — finds the second-largest element.
9. **Second Smallest** — finds the second-smallest element.
10. **Frequency** — determines the frequency of elements in an array.
11. **Repeated Deletion** — identifies and removes repeated elements.
12. **Ascending Sort** — sorts the elements in ascending order.
13. **Merge** — merges two arrays.
14. **Common** — displays the common elements between two arrays.
15. **Rotate** — rotates an array to the left.

---

## 2. Double-Dimensional Arrays (DDA)

Programs based on matrices and two-dimensional array operations

1. **Row Largest**: finds the largest element from each row.
2. **Column Largest**: finds the largest element from each column.
3. **Diagonal Elements**: displays the elements of primary and secondary diagonals.
4. **Row Sum**: finds the sum of elements of each row.
5. **Column Sum**: finds the sum of elements of each column.
6. **Sum of Diagonals**: finds the sum of elements of both diagonals.
7. **Transpose**: finds the transpose of a matrix.
8. **Matrix Sum**: adds two matrices.
9. **Matrix Difference**: subtracts two matrices.
10. **Matrix Multiplication**: multiplies two matrices.
11. **Symmetric**: checks whether a matrix is symmetric.
12. **Upper Triangle**: displays the elements above and including the main diagonal.
13. **Lower Triangle**: displays the elements below and including the main diagonal.
14. **Identity**: checks if a matrix is identity matrix.
15. **Sparse**: checks if a matrix is sparse matrix.
